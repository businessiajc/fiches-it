Fiche 4 — Commandes Linux essentielles

Commandes de base pour s'orienter, lire les journaux et gérer les droits sur un système Linux.

CommandeUsage
pwdAfficher le dossier courant
ls -laLister les fichiers, y compris cachés, avec détails
cd /cheminChanger de dossier
cat fichierAfficher le contenu d'un fichier
grep -r "motif" .Rechercher un motif dans les fichiers
chmod 644 fichierDroits rw-r--r-- (propriétaire lit/écrit, les autres lisent)
chown user:group fichierChanger propriétaire et groupe
ps auxLister les processus en cours
systemctl status serviceÉtat d'un service (systemd)
journalctl -u serviceJournaux d'un service
tail -f /var/log/syslogSuivre un fichier de log en direct
sudo ss -tulpnPorts ouverts et processus associés
df -hEspace disque utilisé/disponible
crontab -lTâches planifiées de l'utilisateur courant
Lecture des droits chmod : un chiffre = rwx en binaire (r=4, w=2, x=1). Exemple 750 = propriétaire rwx (7), groupe r-x (5), autres aucun droit (0).

Réflexe cyber : évitez chmod 777 (tout le monde peut lire/écrire/exécuter) ; préférez le droit minimal nécessaire.
